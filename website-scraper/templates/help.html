Universal Auto Extract

  1. Open New Scraper and keep Universal Auto selected.
  2. Paste a public website URL. A job name is generated automatically when blank.
  3. Keep Auto Detect mode for normal use.
  4. Select Preview first 10 to see the dataset detected by the system.
  5. Start scraping and download CSV, JSON or Excel from the result page.

Auto mode searches for HTML tables, JSON-LD/schema records, repeated product/article cards, list items and visible links. If static HTML is incomplete, it can retry with Playwright.

When to use Custom selectors

  1. Use Preview first. If the wrong dataset is selected, choose Custom.
  2. Right-click the required item in Chrome or Edge and select Inspect.
  3. Find one repeated outer container, such as article.product_pod.
  4. Add selectors for title, price, URL, image or any required field.

Books demo configuration

URL: https://books.toscrape.com/
Container: article.product_pod
Title: h3 a → attribute: title
Price: .price_color → text
Availability: .availability → text
Rating: .star-rating → attribute: class
Product URL: h3 a → link
Next page: li.next a

What “any website” means

The scraper works with publicly accessible HTML and JavaScript pages on a best-effort basis. Every website has a different structure, so Preview and Custom selectors are available when automatic detection is not sufficient.

Common selectors

Class.product
ID#main
Tag + classa.link
Nested.card .price
Attributea[href]

CAPTCHA, login, private pages, paywalls and access blocks are not bypassed. Use an official API where available.
